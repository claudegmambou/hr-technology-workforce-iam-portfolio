# Banking Role-Based Access Control (RBAC)

This folder contains practical exercises and documentation on Role-Based Access Control (RBAC) in banking environments.

## Topics Covered

- RBAC principles and implementation
- Employee roles and responsibilities
- Access permissions and restrictions
- Least privilege
- Segregation of Duties (SoD)
- Access approvals
- Banking security and access governance

## Practical Project

**Northstar Community Bank — Role-Based Access Control Matrix**

A simulated banking project demonstrating how employee roles determine appropriate system access while supporting least privilege and segregation of duties.
