# Microsoft Entra ID Practical Labs

This folder contains hands-on exercises and documentation covering Microsoft Entra ID and identity management.

## Topics Covered

- User and group management
- Authentication and MFA
- Role assignments
- Conditional Access
- Identity Governance
- Access reviews
- Identity provisioning and deprovisioning

## Practical Labs

Practical exercises will be documented as they are completed.

All labs will use authorized learning environments and fictional identities.
