# HRIS-to-IAM Integration Design

This folder contains learning materials and practical documentation exploring how Human Resources Information Systems communicate with Identity and Access Management platforms.

## Topics Covered

- HRIS as the employee system of record
- Employee data synchronization
- Identity provisioning and deprovisioning
- Microsoft Entra ID integration concepts
- APIs and automated workflows
- Identity lifecycle management
- Data accuracy and security controls

## Practical Project

**Northstar Community Bank — HRIS-to-IAM Integration Design**

A simulated design demonstrating how employee lifecycle changes in an HRIS can trigger appropriate identity and access management processes.

The completed project will be added after review.
