# IAM Access Review and Audit

This folder contains practical exercises and documentation on reviewing employee access and identifying inappropriate permissions in a simulated banking environment.

## Topics Covered

- User access reviews
- Excessive permissions
- Dormant and inactive accounts
- Terminated employees with active accounts
- Privileged access reviews
- Audit evidence and documentation
- Access remediation

## Practical Project

**Northstar Community Bank — Identity Governance and Access Review Audit**

A simulated audit project examining employee access records, identifying security risks, and documenting recommended corrective actions.

The completed project will be added after review.
